## 2. 1.21.2 fabric「R1 1688 / OVD 603」偏差归因（非回归，未修码）

### 现象

`1.21.2_fabric_I`：全部门禁绿（持有集零空洞、`ovdMiss=0`、analyzer exit 0、RESULT PASS），
但 R1 `networkReceived`=1688（基线 1705）、R2 `ovdLoaded`=603（基线 636）。

### 定位链（全部位置级 diff 证据）

1. **analyzer `expected` 的真相源是 `chunkTrace.networkReceived`**（`scripts/smoke/analyzer.py:286`）——
   服务端推入网络的柱集在探针时刻的快照，不是独立形状数学。authority 形状两轮均 1529（observed），
   差全部在膨胀环：1705 = 1529 + 176，1688 = 1529 + 159。
2. **今日两场（`_I` 与判别复跑 `_r2`）同为 1688 但环带构成互为 z 镜像**（44 柱差：一场完成 −z 半区裙边
   与 z=−23 边行，另一场完成 +z 半区）→ 环带推送是**方向性波前、逐 run 方向不同**的进度过程，
   客户端断连时刻拍到的是部分环。
3. **对照组**：同为 1705 的场次之间本就存在 45 柱级构成漂移（1.21.3 今日 vs 09-20 `_m1`、
   1.20.1 今日 vs `_light1` 各差 45/45），而 1.20.1 今日 vs `_m1` 逐柱全同——
   计数聚类在 1705/1749 只是「典型快照」，1.21.2 今日恰好拍在更早的进度点。
4. **客户端权威域不受影响**：held=1529 今昔逐柱一致、零空洞；光环柱本就不进客户端视野（S3b 红线），
   analyzer 对光环缺口本就有 halo_only 豁免口径（`analyzer.py:526-536`）。

### 结论

**服务端前沿光环推送在客户端断连时刻的进度快照差，非产品回归；不修码。**
判别复跑 `1.21.2_fabric_I_r2` PASS 存档（同树 1688 可复现、构成镜像证明非几何公式变化）。
